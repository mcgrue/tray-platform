# Future feature plans

These are future candidates, not implementation commitments for Plans 001–003.

- **Running / waiting / ready board:** Track builds, tests, and robot jobs; distinguish working, awaiting human input, and unknown status through explicit heartbeat reporting.
- **Attention-aware sounds:** Coalesce bursts, suppress duplicates, retain events while away, and offer a return summary. Allow selected repeat reminders.
- **Quick thought capture:** Save ideas and errands with optional project context and resurfacing triggers; reuse bookmark capture infrastructure.
- **Transition-based life reminders:** Support “when this finishes,” “when I return,” and departure-time reminders through the inbox.
- **Project launch and handoff:** Open project tools, present the last bookmark, and preserve the next action when stopping. Consider PowerToys Workspaces for saved layouts.
- **Exact browser-tab activation:** Add browser integration if opening links proves insufficient.

# HUMAN QUESTIONS

For each future candidate, establish priority, interruption preferences, acceptable automation, and required integrations before implementation.
